# Kube Prometheus Stack
Kube Prometheus Stack is a collection of monitoring components designed to provide everything needed for monitoring, logging, and alerting in a Kubernetes environment

1. Prometheus
	* Collects metrics from configured targets at given intervals
	* Evaluates metrics
	* Generates alerts if specified conditions are observed
1. Alertmanager
	* Handles alerts sent by Prometheus
1. Grafana
	* Visualization tool
	* Provides dashboards and graphs for visualizing the metrics collected by Prometheus
1. Prometheus Node Exporter
	* Collects system-level metrics like CPU usage, memory consumption, disk I/O, and network traffic
1. Kube State Metrics
	* Collects metrics about Kubernetes objects like deployments, pods, nodes, and namespaces
